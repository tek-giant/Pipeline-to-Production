CI/CD

How I would modernise a banking platform CI/CD pipeline

In a banking environment, delivery needs to be fast, traceable, secure, and recoverable.

The approach

I would design a pipeline that builds once, tests early, scans before deployment, promotes through staging, and uses approval gates before production. 

lint -> test -> build image -> scan -> deploy staging -> smoke test -> approve -> deploy production

What this proves

This shows release discipline, automation thinking, risk awareness, and an understanding of production delivery.
